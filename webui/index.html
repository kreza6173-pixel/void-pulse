Per-app notification mute

Fully blocks an app from posting notifications, via the POST_NOTIFICATIONS runtime permission. Requires the app to target Android 13 (API 33) or higher — apps that don't will show as N/A and aren't reliably controllable this way; use the system notification settings link instead for those.

Notification Listener access

Apps that are allowed to read your notifications (component form: package/Class). Granting this without knowing exactly what the app does is a real privacy risk — only grant it to apps you trust.

DND (Notification Policy) access

Apps allowed to change Do Not Disturb state on their own (package-level, no component needed).

Scheduled DND window

Applied once when Shevery starts this module's session (e.g. on boot), and any time you tap "Re-check now" below. This is not a persistent background timer — see the README's Known Limitations for why. If your DND state matters at an exact minute, apply it manually from Quick Controls instead.
